# AI 分析引擎详细设计

状态：Draft

## 1. 设计原则

- 分层分析而不是一次提示词读完整本书。
- 结构化输出必须经过 schema 验证和语义验证。
- 原文引用由服务端验证，模型不能自行声明“已验证”。
- 人物合并和故事线判断保留候选状态，歧义进入审核队列。
- 每一步可重试、可追踪、可替换模型。
- 模型输出与业务持久化分离；Model Gateway 不直接写业务表。

## 2. 分析阶段

A0 输入检查：确认 work、source version、split version 和 scope 匹配；生成输入 manifest 和 input hash。

A1 章节级提取：每章独立提取摘要、beats、事件候选、人物提及、冲突、信息变化、伏笔候选和证据候选。

A2 实体解析：结合规范化名称、别名、上下文、首次出现和冲突信息生成匹配候选；歧义保留，不自动合并。

A3 事件整理：跨章去重事件候选，保持章节局部顺序与全书叙事顺序；故事内时间单独记录。

A4 故事线综合：根据目标、冲突、人物行动、事件关系和章节分布推断主线/支线/人物弧，生成候选节点。

A5 大纲综合：将章节结果分层聚合为故事弧、卷/阶段和全书结构。结构层级可变，不假设每本书符合固定模板。

A6 伏笔与一致性：寻找线索出现、强化、误导、兑现和未解候选；同时检查矛盾与证据不足。

A7 校验与审阅：schema、外键归属、证据范围、重复记录、关系合法性和人工审核状态。

## 3. 上下文构建

每次模型调用的 context manifest 记录：
- 任务类型和目标；
- 当前章节/文本范围；
- 前文摘要和相关事件；
- 相关人物档案与别名；
- 相关故事线/伏笔；
- 检索命中和原文锚点；
- Canon/用户约束（创作模式）；
- 最大 token 预算及截断策略。

不要把整个项目历史聊天记录作为上下文。检索应围绕任务需要、权限和具体版本进行。

## 4. 提示词资产管理

每个提示词模板有稳定 ID、版本、适用任务、输入 schema、输出 schema、模型能力要求、语言、成本级别和回归样本。

提示词版本变化创建新分析 run，不重写旧 artifact。生产输出记录 template_id、template_version 和 schema_version。

## 5. 结构化输出和验证

验证步骤：
1. 解析 JSON。
2. 校验 JSON Schema。
3. 规范化枚举、空值和长度。
4. 验证 mention_key、event_key、node_key 的唯一性和引用关系。
5. 验证证据引用候选能否在规范化文本中定位。
6. 对事实、推断、猜测分别标记。
7. 通过领域服务持久化为候选对象。
8. 触发人工审核或后续聚合。

模型输出不合格时，允许有限次格式修复；语义冲突不能靠无限重试解决。

## 6. 幂等与并发

- 每个 run 有 idempotency key 和 input hash。
- 每个 step 有稳定 step_key、attempt_count、lease 和 heartbeat。
- 通过唯一键/upsert 防止重复创建同一 run 范围的候选对象。
- worker 领取任务使用 lease；超时后可以回收。
- 模型调用期间不持有数据库长事务。
- 结果写入采用短事务；事务冲突后重新读取状态再决定重试。
- 取消只阻止后续阶段和可取消的在途调用，不删除已完成结果。

## 7. 增量重算与依赖

每个 artifact 记录其输入版本和依赖 manifest。源版本改变时旧产物成为历史；新切分版本产生新的章节 ID。

首期可采取保守策略：重新分析指定章节并重跑跨章节汇总阶段。后续再引入精细的依赖图，减少无关章节重算。

## 8. 质量评估

建立人工标注的小说样本集，覆盖：
- 规则章节标题、无标题章节、目录混入和序言/尾声。
- 同名人物、别名、化名和身份反转。
- 倒叙、插叙、多视角和并行时间线。
- 误导线索、长距离伏笔和开放式结局。
- 主线支线交汇、支线未收束和人物弧。
- Unicode、全角标点、换行规范化和引用偏移。

核心指标：
- chapter split precision/recall；
- evidence exact-match rate；
- entity merge precision 与错误合并率；
- event duplicate rate；
- plotline node coverage；
- unsupported-claim rate；
- human edit/reject rate；
- run success rate、平均延迟和每万字成本。

不能只用模型自评或单一 confidence 分数证明质量。
