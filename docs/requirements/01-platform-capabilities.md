# 平台能力地图

状态：Draft

## 1. 产品边界

ASK 是小说结构化研究、AI 阅读指导和长篇创作平台。三种模式共享文本版本、章节、人物/事件、故事线、证据、异步任务和知识检索基础设施；交互目标和数据语义不同。

- 拆书研究：从已存在的文本逆向还原结构。结论必须可追溯到原文，推断与明示事实必须区分。
- AI 读书：围绕阅读进度帮助用户理解内容、提出问题、形成笔记和输出。
- 小说创作：管理创作者计划、设定、故事结构和正文。计划中的内容不应被当作原著事实。

## 2. 能力域与 ID

### CAP-01 项目与作品管理
- 创建项目，设置研究/阅读/创作/混合模式。
- 一个项目可关联多部作品；作品可以作为主研究对象、参考作品或灵感来源。
- 管理项目成员、角色、归档状态和最近访问记录。
- 项目隔离是权限边界；所有 API 必须验证用户对 project/work 的访问权。

### CAP-02 文本导入与预处理
- 支持 TXT 首发；后续通过统一适配器支持 EPUB、DOCX、HTML 和可检索 PDF。
- 保存原始文件、SHA-256、文件大小、媒体类型、上传者和对象存储键。
- 生成不可变的规范化文本版本，记录解析器、解析器版本和规范化配置。
- 自动识别章节标题、目录、序言、正文、尾声和附录。
- 展示章节预览，允许编辑章节标题、边界、合并和拆分。
- 确认切分后形成不可变 split version；修改需创建新版本。
- 导入任务应支持幂等、失败重试和可诊断错误。

### CAP-03 小说拆解
- 全书概览：题材、叙事视角、核心冲突、主题候选、结构阶段。
- 章节细纲：目标、事件、行动、冲突、信息变化、转折、情绪和章节功能。
- 大纲拆解：全书、卷、幕/阶段、故事弧、章节层级。
- 主线/支线：目标、推进节点、交汇、延迟、收束和遗漏线索。
- 人物分析：目标、需求、动机、能力、弱点、秘密、关系、人物弧线。
- 世界观分析：地点、组织、制度、规则、历史和设定约束。
- 伏笔分析：首次出现、强化、误导、触发、兑现、未解和证据。
- 时间线与事件：叙事顺序和故事内时间分离；支持插叙、倒叙、多线并行。
- 技法分析：视角、冲突、悬念、节奏、场景、对话、意象与主题。
- 作品分析不能把推测的“作者本意”陈述为可验证事实。

### CAP-04 原文证据与审核
- 每个重要分析结论支持零到多个证据锚点。
- 证据锚点包含源版本、切分版本、章节、字符范围、引用文本、哈希和验证状态。
- 结论可标记明示/推断/猜测，以及未审核/接受/拒绝/编辑。
- 用户可修正引用、人物合并、关系方向、事件顺序和故事线归属。
- 用户修改不能覆盖原始 AI 产物；需要版本记录和审计信息。

### CAP-05 阅读导师
- 章节导读、关键问题、阅读目标和背景知识。
- 基于当前阅读位置的问答，回答应给出原文依据或明确标注推断。
- 章节复盘、术语/人物/事件笔记、个人批注和阅读进度。
- 主动提问、阶段测验、观点比较和输出任务。
- 阅读进度与分析版本关联；版本变化后提示进度映射是否需要调整。

### CAP-06 小说创作
- 故事定位、题材、主题、读者期待和核心冲突。
- Canon/设定集：人物、关系、地点、组织、规则、秘密、已发生事件。
- 主线、支线、人物弧、伏笔计划和全书/分卷/章节/场景大纲。
- 正文编辑、章节版本、局部重写、扩写、压缩、风格约束和人工确认。
- 一致性检查：人物、时间、地点、能力、设定、信息知情范围、伏笔和因果。
- 计划大纲与已写正文必须区分状态；AI 不得默默覆盖作者确认的设定。

### CAP-07 AI 任务与模型网关
- 异步任务、阶段/步骤、进度、重试、取消、恢复和幂等。
- 每一步记录模型提供方、模型 ID、提示词版本、结构 schema 版本、token、延迟和验证结果。
- 支持多模型流水线，不能假设整本书只使用一个模型。
- 结构化输出必须经过服务端 schema 验证和语义校验。
- 支持按章节重算及依赖失效标记；保留历史结果。

### CAP-08 检索与知识库
- 按作品、版本、章节和用户权限限定检索范围。
- 首期关键词检索和结构查询优先；向量检索、重排按评估结果增加。
- 检索结果应携带章节、位置和版本，不能只返回无来源的文本片段。
- 不把一部作品的角色/设定自动合并到另一部作品；跨作品比较必须显式授权并保留来源。

### CAP-09 项目治理与运维
- 角色与访问控制、审计日志、删除/保留策略、配额和任务限流。
- 健康检查、任务队列积压、失败率、模型延迟和 token 用量监控。
- 备份恢复、迁移回滚、配置管理、密钥管理和日志脱敏。

## 3. 能力优先级

P0：项目/作品、TXT 导入、规范化文本、章节切分与确认、分析任务、章节细纲、人物/事件提取、证据锚点、基本审核界面。

P1：跨章节人物消歧、主线/支线、大纲树、伏笔关系、事件因果、增量重算和完整任务恢复。

P2：阅读导师、笔记、测验、阅读进度。

P3：Canon、原创大纲、正文版本、一致性检查、写作技法库。

## 4. 非目标

首期不建设公开发布平台、小说社区、付费内容市场、实时多人协同编辑、自动发布到第三方平台或不受约束的全自动百万字生成系统。
