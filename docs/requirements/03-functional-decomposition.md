# 平台功能拆解与验收矩阵

状态：Draft

## 1. 项目与作品

| 功能 ID | 功能 | 主要规则 | 验收 |
|---|---|---|---|
| FR-PROJ-001 | 创建项目 | 名称非空；创建人与 owner 成员关系在同一事务建立 | 新项目仅授权成员可见 |
| FR-PROJ-002 | 项目成员 | owner/editor/viewer 权限明确 | viewer 无法执行修改接口 |
| FR-WORK-001 | 创建作品 | work_type 为 published/original | 作品能被一个或多个项目引用 |
| FR-WORK-002 | 项目关联作品 | role 为 primary/reference/inspiration | 同一项目不重复关联同一作品 |

## 2. 文本导入与切分

| 功能 ID | 功能 | 主要规则 | 验收 |
|---|---|---|---|
| FR-SRC-001 | 上传原文件 | 校验媒体类型、大小、哈希和权限 | 原始字节可校验，重复上传可识别 |
| FR-SRC-002 | 规范化 | 记录 parser/normalizer 版本和配置 | 同一输入和同一配置可追溯 |
| FR-SRC-003 | 自动分章 | 输出标题、顺序和源文本字符区间 | 所有章节区间合法、无意外重叠 |
| FR-SRC-004 | 手工修正 | 修改产生 draft split revision | 已确认版本不被覆盖 |
| FR-SRC-005 | 确认切分 | 只有 confirmed split 可启动源文本分析 | 错误版本组合被服务端拒绝 |
| FR-SRC-006 | 查看原文 | 支持章节定位和证据高亮 | 引用范围与规范化文本一致 |

## 3. 拆书分析

| 功能 ID | 功能 | 主要规则 | 验收 |
|---|---|---|---|
| FR-ANL-001 | 创建分析任务 | 异步、幂等、输入版本固定 | 重复请求不产生重复 run |
| FR-ANL-002 | 章节细纲 | 输出符合 schema，包含事件和章节作用 | JSON schema 和业务校验均通过 |
| FR-ANL-003 | 人物/实体提取 | 别名与实体分开；歧义保留候选 | 不因名字相似自动合并 |
| FR-ANL-004 | 事件提取 | 区分叙事顺序和故事内时间 | 插叙不导致时间线被错误排序 |
| FR-ANL-005 | 故事线推断 | 主线/支线节点可追溯章节和事件 | 每个节点有来源或明确标记为推断 |
| FR-ANL-006 | 大纲树生成 | 层级可变，不强制固定三幕/三卷 | 支持任意合法父子层级 |
| FR-ANL-007 | 伏笔分析 | 区分候选、强化、兑现、未解 | 不能仅凭相似词判定伏笔兑现 |
| FR-ANL-008 | 全书汇总 | 使用分层摘要和检索证据 | 不依赖一次输入整本全文的单次提示 |

## 4. 审核与结构编辑

| 功能 ID | 功能 | 主要规则 | 验收 |
|---|---|---|---|
| FR-REV-001 | 审核结论 | 接受/拒绝/编辑保留审计 | 原始生成结果仍可查 |
| FR-REV-002 | 人物合并/拆分 | 同一 work 范围内事务执行 | 引用无悬空，冲突有报告 |
| FR-REV-003 | 编辑故事线 | 节点顺序、关系、状态可编辑 | 并发修改返回 409 而非覆盖 |
| FR-REV-004 | 版本比较 | 对比产物版本和输入版本 | 显示变化及失效证据 |

## 5. 阅读与创作（后续阶段）

阅读：
- FR-READ-001 阅读进度和书签。
- FR-READ-002 章节导读和上下文问答。
- FR-READ-003 笔记、批注和术语表。
- FR-READ-004 阶段测验与输出任务。

创作：
- FR-WRITE-001 Canon/设定集。
- FR-WRITE-002 planned outline 和故事线。
- FR-WRITE-003 章节细纲和正文版本。
- FR-WRITE-004 基于局部上下文生成/改写。
- FR-WRITE-005 人物、时间、地点、规则、伏笔和因果一致性检查。

每项后续功能进入开发前，必须补齐请求/响应、权限、状态变更、异常、测试用例和成本预算。

## 6. 通用非功能需求

- NFR-SEC-001：所有资源访问执行项目成员鉴权。
- NFR-DATA-001：源版本、确认后的切分版本和已发布 artifact revision 不原地覆盖。
- NFR-JOB-001：异步任务可恢复、幂等、可观测。
- NFR-AI-001：结构化模型输出经过 schema 和语义校验。
- NFR-EVD-001：引用必须可验证，不能把未经校验的片段标成已验证。
- NFR-OBS-001：日志默认不记录整本正文或完整提示词。
- NFR-TEST-001：迁移、版本一致性、证据偏移和重试均有自动化测试。
